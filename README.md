# Comunidad de Kivo Store

Opiniones y calificaciones de aplicaciones disponibles en Kivo a través de F-Droid y GitHub.

## Cómo participar

Desde la ficha de una app en Kivo, conecta tu cuenta de GitHub, elige una calificación de 1 a 5 y escribe tu experiencia. Kivo pide confirmar antes de publicar. Tu nombre de GitHub y tu opinión serán públicos.

Las estrellas de un proyecto de GitHub son independientes de las calificaciones de Kivo. El cliente comprueba localmente la instalación; esto no constituye una verificación de instalación en servidor.

## Normas de la comunidad

- Comenta sobre tu experiencia con la aplicación.
- No publiques contraseñas, tokens ni datos personales.
- Evita spam, acoso, suplantación y enlaces engañosos.
- Los comentarios pueden moderarse mediante las herramientas de GitHub.

## Integración

Este repositorio está dedicado a las reseñas de Kivo. No sustituye los canales de soporte de los desarrolladores. Los hilos identifican el paquete Android y los comentarios de Kivo usan el formato `kivo-review-v1`. Se toma la última calificación válida de cada cuenta para cada app.

La conexión con la aplicación está en preparación.
